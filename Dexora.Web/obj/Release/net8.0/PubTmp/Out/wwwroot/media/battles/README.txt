DEXORA CINEMATIC BATTLE CLIPS

Place video clips you have permission to use in this folder.
Name each file with the Pokemon API name, for example:
  charizard.webm   (preferred)
  charizard.mp4
  pikachu.webm
  gengar.mp4

Dexora will autoplay the matching clip muted, loop it, and make it cover the entire Pokemon profile hero.
If no clip exists, Dexora falls back to a moving Pokemon sprite/artwork presentation.
For best results use 16:9 or wider HD video (1920x1080 recommended) with the Pokemon/action kept near the center.
